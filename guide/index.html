What RSRoute is

RSRoute is a small FastAPI service you run yourself. It holds your provider API keys, exposes one endpoint per provider, and returns every response in the same JSON shape. Your application talks to RSRoute instead of talking to four different SDKs.

There are two ways to use it, and they share the same contract:

  • As a server — run it with python run_server.py and call the HTTP routes from any language.
  • As a library — import the provider wrappers from app/providers/ directly, no HTTP hop.

On top of that, the separate rsroute Python package is a thin client that wraps the HTTP routes and handles the master key, request shaping and the agentic tool loop for you.

Design constraints

Stateless — no database, no session store, no queue. Streaming is not supported in v1; responses are returned in full. Tools are advertised to the model but never executed server-side.

Request body

Server parameters

Every route accepts a JSON body. These are the fields the server reads. Anything not listed here is ignored — the routes declare their parameters explicitly.

Common RSRoute request parameters
Parameter Type Default Details
query opt any "Hello" Input to the model. A plain string is wrapped into a single user message; a list is passed through as a message array.
master_key opt string "" Gateway key. Required only when ENABLE_AUTH=true. Must start with RSRoute_ and be at least 14 characters.
model opt string per provider Provider model identifier. Defaults differ per route — see each provider guide.
temperature opt float 0.7 Sampling creativity. 0.0 is deterministic, higher is more varied.
max_tokens opt integer 2048 Upper bound on generated tokens. OpenRouter routes default to 4096 instead.
top_p opt float 1.0 Nucleus sampling boundary. Supported by Gemini and Mistral only — removed from Groq and OpenRouter.
end_point opt string | null null Custom base URL for the underlying provider client (proxy or self-hosted).
thinking_level opt string | null null Gemini only. Controls reasoning depth on Gemini 3+ models.
thinking_budget opt integer | null null Gemini only. Token budget for reasoning / chain-of-thought.
tools_info opt array<object> null Agent routes only. List of {"name", "description"} pairs. See the agent guide.

OpenRouter-only fields

The OpenRouter routes accept five additional fields on top of the common set.

OpenRouter-only request parameters
Parameter Type Default Details
app_title opt string "RSRoute" App name reported to OpenRouter rankings.
app_url opt string "https://www.rsroute.freedev.app/" App URL reported to OpenRouter rankings.
app_categories opt array<string> | null null Optional category tags for the OpenRouter dashboard.
max_retries opt integer 2 Automatic retry attempts on upstream failure.
providers opt object | null null OpenRouter provider preferences, e.g. {"order": ["OpenAI"]}.

Environment variables

Provider keys live in .env on the gateway host. Applications never see them.

Server environment variables
Variable Required Details
GOOGLE_API_KEY for gemini Missing key returns error: "No Google API Key Found, try to edit `.env`".
MISTRAL_API_KEY for mistral Missing key returns error: "No MistralAI API Key Found, try to edit `.env`".
GROQ_API_KEY for groq Missing key returns error: "No Groq API Key Found, try to edit `.env`".
OPENROUTER_API_KEY for openrouter Missing key returns error: "No OpenRouter API Key Found, try to edit `.env`".
RSRoute_MASTER_KEY if auth on Must start with RSRoute_ and be at least 14 characters.
ENABLE_AUTH opt Defaults to false. Set to true to require master_key on every request.
HOST / PORT opt Bind address for run_server.py. Defaults 127.0.0.1 and 8000.
Auth defaults to off

ENABLE_AUTH is false unless you set it. With auth off, anyone who can reach the port can spend your provider credits. Set it to true before exposing the gateway.

Plain HTTP

REST API example

Every route is a plain POST with a JSON body. No SDK, no special headers — the master key travels in the body, not in an Authorization header. 

import requests

resp = requests.post(
    "http://localhost:8000/v1/gemini/chat",
    json={
        "query": "Explain vector databases",
        "master_key": "RSRoute_my_key",
        "model": "gemini-3.5-flash-lite",
        "temperature": 0.7,
        "max_tokens": 2048,
    },
    timeout=60,
)

data = resp.json()

# Errors arrive in-band with HTTP 200 — check the body.
if data["error"] != "No Error Found":
    raise RuntimeError(data["error"])

print(data["content"])
const resp = await fetch("http://localhost:8000/v1/gemini/chat", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    query: "Explain vector databases",
    master_key: "RSRoute_my_key",
    model: "gemini-3.5-flash-lite",
    temperature: 0.7,
    max_tokens: 2048,
  }),
});

const data = await resp.json();

// Errors arrive in-band with HTTP 200 — check the body.
if (data.error !== "No Error Found") {
  throw new Error(data.error);
}

console.log(data.content);
curl -X POST http://localhost:8000/v1/gemini/chat \
  -H "Content-Type: application/json" \
  -d '{
    "query": "Explain vector databases",
    "master_key": "RSRoute_my_key",
    "model": "gemini-3.5-flash-lite",
    "temperature": 0.7,
    "max_tokens": 2048
  }'

Swap the path to change provider: /v1/mistral/chat, /v1/groq/chat, /v1/openrouter/chat. The body shape stays the same.

Discovering routes at runtime

GET / returns a machine-readable index of every route, and each provider exposes a parameter endpoint describing the fields it accepts. 

# Route index
curl http://localhost:8000/

# Parameter info for one provider
curl http://localhost:8000/v1/gemini/parameter
curl http://localhost:8000/v1/mistral/parameter
curl http://localhost:8000/v1/groq/parameters
curl http://localhost:8000/v1/openrouter/parameters
Optional wrapper

rsroute client

rsroute is a thin Python package that wraps the HTTP routes. It resolves the master key from .env, shapes the request, and runs the agentic tool loop for you. 

pip install rsroute

Requires Python 3.14+.

Chat model

from rsroute.chat_models import ChatGemini

gemini = ChatGemini(
    model="gemini-3.5-flash-lite",
    rsroute_url="http://0.0.0.0:8000",  # default
    temperature=0.7,
)

result = gemini.invoke(query="What is GitHub?")
print(result["content"])

Agent

from rsroute.agents import GeminiAgent

gemini_agent = GeminiAgent(
    tools=[web_search],       # LangChain StructuredTool list
    max_tool_calls=10,       # default
)

result = gemini_agent.invoke(query="Latest news on GPT-6 Astra")
print(result["content"])
print(result["tools_used"])
Master key resolution

The client looks for the key in this order: the master_key argument, then rsroute_token, master_key, rsroute_key, rsroute_master_key (upper or lower case) in the environment or .env. If none is found it raises ValueError.

Full class-by-class reference: chat model guide and agent guide.

Contract

Response envelope

Every successful response has the same keys, regardless of provider. Agent routes add tool_calls. 

{
  "content": "Here is the summary…",
  "query": ["Summarise this document"],
  "error": "No Error Found",
  "login": true,
  "auth": true,
  "usage_metadata": { /* tokens in / out */ },
  "response_metadata": { /* provider raw */ },
  "initlized_parameters": {
    "model": "gemini-3.5-flash-lite",
    "temperature": 0.7
  },
  "tool_calls": []
}

initlized_parameters is spelled that way in the API — keep the typo when you read the field.

Failure modes

Errors

RSRoute reports failures in-band. Auth failures, missing provider keys and provider exceptions all return HTTP 200 with error populated and login: false.

  • Authentication Failed — master_key missing, malformed or wrong.
  • Invalid Request — provider key missing from .env, or the model failed to initialise.
  • Request Error — the provider call itself raised.
Check the body, not the status

A 200 does not mean success. Always compare error against "No Error Found" before using content.
