Provider guide

OpenRouter

One key, hundreds of models. The OpenRouter routes accept five extra fields that no other provider has — provider routing preferences, app attribution and retry control.

Overview

What it is

OpenRouter aggregates frontier and open-weight models behind a single API. RSRoute wraps it with the standard envelope and forwards OpenRouter's own routing and attribution options.

Default model: deepseek/deepseek-v4.1-flash. Requires OPENROUTER_API_KEY in the gateway's .env.

Different max_tokens default

OpenRouter routes default max_tokens to 4096, not 2048 like the other three providers.

Endpoints

Routes

OpenRouter routes
Method Path Purpose
POST /v1/openrouter/chat Plain text-to-text chat.
POST /v1/openrouter/agent Tool-binding agent. Requires tools_info.
GET /v1/openrouter/parameters Parameter info. /parameter is an alias.
Request body

Server parameters

The common set, minus top_p, plus five OpenRouter-specific fields.

OpenRouter request parameters
Parameter Type Default Details
query opt any "Hello" String is wrapped into a user message; a list is passed through.
master_key opt string "" Checked only when ENABLE_AUTH=true.
model opt string "deepseek/deepseek-v4.1-flash" Any OpenRouter model identifier.
temperature opt float 0.7 Sampling creativity.
max_tokens opt integer 4096 Upper bound on generated tokens. Higher default than other providers.
app_title opt string "RSRoute" App name reported to OpenRouter rankings.
app_url opt string "https://www.rsroute.freedev.app/" App URL reported to OpenRouter rankings.
app_categories opt array<string> | null null Optional category tags for the OpenRouter dashboard.
max_retries opt integer 2 Automatic retry attempts on upstream failure.
providers opt object | null null OpenRouter provider preferences, e.g. {"order": ["OpenAI"]}.
end_point opt string | null null Override the OpenRouter base URL (proxy / self-hosted).
tools_info agent only array<object> null List of {"name", "description"} pairs.
top_p Not supported. Removed from the route signature and from the parameter info.
Model ids

Choosing a model

OpenRouter model ids are namespaced as vendor/model. Pass any id OpenRouter serves — no code change, just a different model value. 

# Default
"deepseek/deepseek-v4.1-flash"

# Other examples
"openai/gpt-4o-mini"
"anthropic/claude-sonnet-4"
"meta-llama/llama-3.3-70b-instruct"

Provider routing

The providers object is forwarded to OpenRouter's own routing layer. Use it to prefer or exclude specific upstreams. 

{
  "providers": {
    "order": ["DeepSeek", "Together"],
    "allow_fallbacks": true
  }
}
Passed through unvalidated

RSRoute does not inspect the providers object — it hands it straight to the OpenRouter client. Invalid keys surface as a provider error.

App attribution

app_title, app_url and app_categories are reported to OpenRouter so your usage shows up correctly in its rankings and dashboard. 

{
  "app_title": "My App",
  "app_url": "https://example.com",
  "app_categories": ["coding", "research"]
}
Plain HTTP

REST example

import requests

resp = requests.post(
    "http://localhost:8000/v1/openrouter/chat",
    json={
        "query": "Explain mixture-of-experts",
        "master_key": "RSRoute_my_key",
        "model": "deepseek/deepseek-v4.1-flash",
        "temperature": 0.7,
        "max_tokens": 4096,
        "app_title": "My App",
        "app_url": "https://example.com",
        "max_retries": 2,
        "providers": {"order": ["DeepSeek"]},
    },
    timeout=60,
)

data = resp.json()
if data["error"] != "No Error Found":
    raise RuntimeError(data["error"])

print(data["content"])
const resp = await fetch("http://localhost:8000/v1/openrouter/chat", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    query: "Explain mixture-of-experts",
    master_key: "RSRoute_my_key",
    model: "deepseek/deepseek-v4.1-flash",
    temperature: 0.7,
    max_tokens: 4096,
    app_title: "My App",
    app_url: "https://example.com",
    max_retries: 2,
    providers: { order: ["DeepSeek"] },
  }),
});

const data = await resp.json();
if (data.error !== "No Error Found") {
  throw new Error(data.error);
}

console.log(data.content);

rsroute client

rsroute client

from rsroute.chat_models import ChatOpenRouter

openrouter = ChatOpenRouter(
    model="deepseek/deepseek-v4.1-flash",
    temperature=0.7,
    max_tokens=4096,
    app_title="My App",
    app_url="https://example.com",
    app_categories=["coding"],
    max_retries=2,
    providers={"order": ["DeepSeek"]},
)

result = openrouter.invoke(query="Hello OpenRouter!")
print(result["content"])

OpenRouter is an alias for ChatOpenRouter.

Agent

from rsroute.agents import OpenRouterAgent

agent = OpenRouterAgent(
    tools=[web_search],
    model="deepseek/deepseek-v4.1-flash",
    providers={"order": ["DeepSeek"]},
)

result = agent.invoke(query="Search the latest open-weight model releases")
print(result["content"])
print(result["tools_used"])

ChatOpenRouterAgent is an alias for OpenRouterAgent.

Gotchas

Notes

  • /v1/openrouter/parameters and /v1/openrouter/parameter both work.
  • Missing OPENROUTER_API_KEY returns error: "No OpenRouter API Key Found, try to edit `.env`" with HTTP 200.
  • top_p is removed from this route, same as Groq.
  • The parameter endpoint rewrites the model, max_tokens and temperature descriptions to name the OpenRouter defaults.
  • Embedding endpoints are not implemented.
