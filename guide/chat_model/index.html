Chat models

Basics

Overview

A chat model is the simplest path through RSRoute: send text, get text back. The client builds the JSON body, posts it to the matching /v1/<provider>/chat route, and returns the parsed response dictionary. 

from rsroute.chat_models import ChatGemini

gemini = ChatGemini(model="gemini-3.5-flash-lite")
result = gemini.invoke(query="What is GitHub?")

print(result["content"])

invoke() is the canonical method. __call__ and generate() both forward to it, so gemini("…") and gemini.generate("…") behave the same.

Setup

Install & master key

pip install rsroute

Requires Python 3.14+.

The client needs a master key. It resolves one in this order:

  1. The master_key constructor argument.
  2. rsroute_token / RSROUTE_TOKEN
  3. master_key / MASTER_KEY
  4. rsroute_key / RSROUTE_KEY
  5. rsroute_master_key / RSROUTE_MASTER_KEY

Steps 2–5 are read from the environment, after loading .env from the current working directory. If nothing is found, the constructor raises ValueError. 

# .env
rsroute_token=RSRoute_my_key
Auth is optional server-side

The client always sends a key, but the server only checks it when ENABLE_AUTH=true. With auth off, any key-shaped string is accepted.

Constructor

Arguments

These are the arguments every chat model class accepts. Provider-specific extras are listed in the next section.

Chat model constructor arguments
Argument Type Default Details
model opt str | None None Model id. When omitted, the server applies its own default for that provider.
master_key opt str | None None Gateway key. Falls back to .env / environment.
rsroute_url opt str | None http://0.0.0.0:8000 Base URL of your gateway. The provider path is appended automatically.
system_prompt opt str | SystemMessage | any None Prepended as a system message. Non-strings are stringified.
temperature opt float | None None Omitted from the request when None, so the server default (0.7) applies.
max_tokens opt int | None None Omitted when None; server default is 2048 (4096 on OpenRouter).
timeout opt int 30 HTTP timeout in seconds for the requests.post call.
end_point opt str | None None Forwarded to the server as the provider's own base URL override.
**kwargs opt any — Any extra keyword is forwarded verbatim in the request body, as long as the value is not None.
None means "let the server decide"

The client only includes a field in the request body when its value is not None. Leaving temperature unset is not the same as passing 0.0 — the server's default is used instead.

Differences

Per provider

All four classes share the base arguments. Only Gemini adds extras, and only OpenRouter adds its own set.

ChatGemini

Adds thinking_level and thinking_budget for Gemini 3+ reasoning control. Default model: gemini-3.5-flash-lite. 

from rsroute.chat_models import ChatGemini

gemini = ChatGemini(
    model="gemini-3.5-flash-lite",
    temperature=0.7,
    max_tokens=2048,
    thinking_level="high",
    thinking_budget=1024,
)

ChatMistral

Default model: mistral-small-2603. Aliases ChatMistralAI and MistralAI point at the same class. 

from rsroute.chat_models import ChatMistral

mistral = ChatMistral(
    model="mistral-small-2603",
    temperature=0.7,
)

ChatGroq

Default model: openai/gpt-oss-120b. The Groq route does not accept top_p. 

from rsroute.chat_models import ChatGroq

groq = ChatGroq(
    model="openai/gpt-oss-120b",
    temperature=0.7,
)

ChatOpenRouter

Default model: deepseek/deepseek-v4.1-flash. Adds app_title, app_url, app_categories, max_retries and providers. Alias OpenRouter. 

from rsroute.chat_models import ChatOpenRouter

openrouter = ChatOpenRouter(
    model="deepseek/deepseek-v4.1-flash",
    app_title="My App",
    app_url="https://example.com",
    max_retries=2,
    providers={"order": ["DeepSeek"]},
)

Full field reference: OpenRouter guide.

Input shaping

Messages & system prompt

query accepts three shapes, and the client normalises them before sending:

  • A string — wrapped into [{"role": "user", "content": "…"}].
  • A list — passed through untouched, so you can send a full conversation.
  • Nothing — the body is sent without a query key at all.

When system_prompt is set and you pass a plain string, the system message is prepended automatically. 

from rsroute.chat_models import ChatGemini

gemini = ChatGemini(
    model="gemini-3.5-flash-lite",
    system_prompt="You are a terse assistant. Answer in one sentence.",
)

# Sent as: [system, user]
gemini.invoke(query="What is a vector database?")

# A list is passed through as-is — no system message is injected.
gemini.invoke(query=[
    {"role": "user", "content": "Hi"},
    {"role": "assistant", "content": "Hello!"},
    {"role": "user", "content": "Continue."},
])
Lists bypass the system prompt

If you pass a list, the client does not prepend system_prompt — include the system message yourself in that list.

Output

Return value

invoke() returns the parsed JSON body as a plain dict. It does not raise on provider errors — check error yourself. 

result = gemini.invoke(query="Hello")

if result["error"] != "No Error Found":
    raise RuntimeError(result["error"])

print(result["content"])
print(result["usage_metadata"])

The only exception the client raises itself is RuntimeError, when the HTTP request fails outright (connection refused, DNS failure, timeout).

get_params() returns the parameters the client sent, with master_key stripped out — useful for logging.

Under the hood

REST equivalent

The client is a thin wrapper. This is exactly what it sends for the Gemini example above. 

import requests

resp = requests.post(
    "http://0.0.0.0:8000/v1/gemini/chat",
    json={
        "master_key": "RSRoute_my_key",
        "model": "gemini-3.5-flash-lite",
        "temperature": 0.7,
        "query": [{"role": "user", "content": "Hello"}],
    },
    timeout=30,
)

print(resp.json()["content"])
const resp = await fetch("http://0.0.0.0:8000/v1/gemini/chat", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    master_key: "RSRoute_my_key",
    model: "gemini-3.5-flash-lite",
    temperature: 0.7,
    query: [{ role: "user", content: "Hello" }],
  }),
});

const data = await resp.json();
console.log(data.content);
